# 时间码 vs 速率码：SiClink R4 实验结果（阴性）

**日期**：2026-11-28。基于何飞参与的 Nature Communications 2025（temporal coding）思路。
**协议**：只用 repeat1-3 训练；repeat4 只用于评估。线性解码器为单层 softmax 回归
（AdamW，lr=1e-3，wd=0.1，20 epochs，batch 512，seed 42）。无官方 OCF。

## 1. R4 主实验（每 session 用 R1-3 归一化，训练全部 session，测 R4）

两鼠等权宏平均：

| 特征 | 维度（鼠1/鼠2） | Top-1 | Recall@32 | NLL |
|---|---|---:|---:|---:|
| rate250（250ms 总计数） | 134 / 78 | **0.755%** | **9.36%** | **7.625** |
| rate50（5×50ms） | 670 / 390 | 0.660% | 8.75% | 8.253 |
| temporal10 + rate250 | 3484 / 2028 | 0.491% | 6.32% | 7.915 |
| temporal10（25×10ms） | 3350 / 1950 | 0.364% | 5.61% | 7.992 |
| temporal25（10×25ms） | 1340 / 780 | 0.482% | 7.72% | 8.114 |

**结论**：在相同线性解码器、相同训练/测试口径下，**rate250 最好，时间分辨特征全部更差**；
10ms 时间展开把特征维度扩大约 25 倍，但在这个 2748 类单 trial 任务上只增加了噪声。
这与实验 53 的 10ms 视图更差一致。

## 2. 严格跨 session 压力测试（训练 session1-3，测 session4）

| 特征 | 鼠1 Top-1 / R@32 | 鼠2 Top-1 / R@32 |
|---|---:|---:|
| rate250 | 0.62% / 8.73% | 0.04% / 2.44% |
| rate50 | 0.73% / 8.66% | 0.07% / 1.97% |
| temporal10 | 0.36% / 5.90% | 0.00% / 2.04% |
| temporal10 + rate250 | 0.51% / 6.70% | 0.07% / 2.29% |

**结论**：跨 session 的分布偏移远大于时间码带来的收益；mice2 几乎完全失效，NLL 达 12–25，
说明线性解码器在未见 session 上严重过置信。这个协议下不能把失败单独归因于时间码。

## 3. 表征稳定性（无分类器）

对每个 session 用 repeat1-3 的每字平均响应，计算 2748×2748 余弦相似度矩阵；
跨 session 相关与 repeat 分半相关：

| 特征 | 鼠1 跨 session 均值 | 鼠1 分半 | 鼠2 跨 session 均值 | 鼠2 分半 |
|---|---:|---:|---:|---:|
| rate250 | -0.0001 | 0.0002 | 0.0002 | -0.0005 |
| rate50 | -0.0003 | 0.0001 | -0.0002 | -0.0003 |
| temporal25 | -0.0001 | -0.0001 | -0.0005 | -0.0004 |
| temporal10 | 0.0001 | 0.0001 | -0.0006 | -0.0002 |

**结论**：所有相关都接近 0（|r|<0.001），没有证据表明时间码表征更稳定。
直接原因是每个字只有 3 次 repeat，单字响应本身的跨 repeat 相关只有约 0.025；
per-character 平均仍以噪声为主，无法估计稳定的表征几何。论文中的 15 天、1204 个
tracked units、每个刺激多次重复的条件在这里不成立。

## 4. 总体判断

- **简单时间码方向在当前数据上关闭**：原始 10/25ms 计数 + 线性解码既没有提升 Top-1，
  也没有提升跨 session 稳定性。
- 这不是对论文的否定；论文的时间码依赖高单元数、多 trial 平均、跨天稳定跟踪。
  SiClink 的 134/78 units、3 次训练 repeat、2748 类单 trial 条件信噪比低一个量级。
- 若继续追时间码，需要**学习式时间编码器**（per-unit temporal kernel / temporal conv）
  加可靠性加权，而不是把 10ms 计数直接 flatten；但当前证据不支持优先投入。
- 建议回到已验证的 R4 最优管线（CSLS + 跨分支集成 + 250ms，Top-1 2.60%），
  或转向 repeat-aware 自监督预训练；时间码暂不作为主线。
